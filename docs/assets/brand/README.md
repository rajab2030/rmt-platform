# RMT brand assets

The official RMT logo: a shield with an integrated "RMT" monogram and a
checkmark, next to the "RMT" wordmark and the descriptor
"Risk-Mitigated Transactions Platform".

## Vector (use these first)

| File | Use |
|---|---|
| `rmt-logo.svg` | Full lockup for dark backgrounds. Transparent. |
| `rmt-logo-light.svg` | Full lockup for light backgrounds. Transparent. |
| `rmt-mark.svg` | Shield mark only, dark backgrounds. Site header. |
| `rmt-mark-light.svg` | Shield mark only, light backgrounds. |
| `rmt-app-icon.svg` | Mark on a dark rounded square. Favicons and app icon. |

The SVGs are a flat redraw traced from `rmt-logo-original.jpg`. The 3D bevel
and texture are replaced by flat silver (`#D6D8DC` dark / `#2E333A` light) and
gold (`#CDB98A` dark / `#9C7D41` light). Text is converted to outlines from
Montserrat (SIL Open Font License), so no font needs to be installed.

## Raster

| File | Use |
|---|---|
| `rmt-logo-original.jpg` | Master image as supplied by the project owner (2576×1438). |
| `rmt-logo-banner.jpg` | Full lockup cropped from the master, 1600 px wide. |
| `rmt-logo-mark-512.png` | Mark only, square, 512×512, cropped from the master. |
| `rmt-logo-mark-180.png` | Mark only, 180×180. Apple touch icon. |
| `rmt-favicon-32.png` | Mark only, 32×32. Fallback favicon for browsers without SVG icons. |

## Known limitations

- At 16 px the monogram inside the shield blurs. Use 32 px or larger where possible.
