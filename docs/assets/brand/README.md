# RMT brand assets

The official RMT logo: a shield with an integrated "RMT" monogram and a
checkmark, next to the "RMT" wordmark and the descriptor
"Risk-Mitigated Transactions Platform".

| File | Use |
|---|---|
| `rmt-logo-original.jpg` | Master image as supplied by the project owner (2576×1438). |
| `rmt-logo-banner.jpg` | Full lockup (mark + wordmark + descriptor), 1600 px wide. README and website headers. |
| `rmt-logo-mark-512.png` | Mark only, square, 512×512. Avatars, social previews. |
| `rmt-logo-mark-180.png` | Mark only, 180×180. Site header and Apple touch icon. |
| `rmt-favicon-32.png` | Mark only, 32×32. Browser favicon. |

All crops are taken directly from `rmt-logo-original.jpg`, without redrawing.

## Known limitations

- The master is a raster mockup on a dark textured background. There is no
  vector (SVG) version and no transparent-background version yet, so the logo
  is meant for dark backgrounds only.
- At 32 px the monogram inside the shield is hard to read. A simplified
  favicon may be needed later.
