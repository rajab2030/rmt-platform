# RMT-012.0.1.1 Context Model Design

## Status

Design Phase

## Objective

Define the foundational context model required for RMT Intelligence to understand platform components, their roles, importance, dependencies, and operational state.

## Design Principle

Intelligence decisions must not depend only on metrics.

The platform must combine:

- Current state
- Historical behavior
- Component identity
- Operational context
- Dependencies

to produce meaningful analysis.

---

# Component Context Model

A Component Context represents the operational understanding of a platform component.

## Component Identity

Defines what the component is.

Attributes:

- Name
- Type
- Version
- Platform location

name: portainer
